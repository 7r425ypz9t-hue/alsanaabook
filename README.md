# كتاب السَّنْع

**آداب المجتمع الإماراتي وقيمه في المجلس والضيافة والأسرة والطريق والفضاء الرقمي**
منهج تعليمي متدرّج للصفوف من السادس إلى الثاني عشر (الحلقتان الثانية والثالثة).

> «الساير ساير على اسنعه»: كلٌّ يعامل الناس بما تربّى عليه من خُلُق.

**حالة النص:** مسودة منهجية للتحكيم · أكتوبر ٢٠٢٦
**المؤلف:** د. ماجد عبدالله بوشليبي · جميع الحقوق محفوظة للمؤلف.

---

## الطبعات

| الطبعة | الملف | الاستخدام |
|---|---|---|
| الصفحة الرقمية | [`book/index.html`](book/index.html) | للقراءة على الشاشة، بفهرس ثابت ووضعين فاتح وداكن |
| طبعة PDF (A4) | [`dist/kitab-alsanaa.pdf`](dist/kitab-alsanaa.pdf) | للطباعة والتوزيع على لجان التحكيم؛ مفاتيح الإجابة ظاهرة |
| طبعة Word | [`dist/kitab-alsanaa.docx`](dist/kitab-alsanaa.docx) | للتحرير والتعليق؛ اتجاه كامل من اليمين إلى اليسار وفهرس آلي |

## بنية الكتاب

| القسم | المحتوى |
|---|---|
| قراءة المجلس العلمي | مواطن القوة في المسودة الأولى، والتصويبات الجوهرية، والإضافات، وضوابط النزاهة العلمية |
| التقديم ودليل المعلم | فلسفة المنهج، والمستويات الثلاثة، ومصفوفة النطاق والتتابع، ومنهجية التقييم |
| الوحدة ١ | السنع: المفهوم والجذور والهوية *(مضافة)* |
| الوحدة ٢ | سنع المجلس |
| الوحدة ٣ | سنع الضيافة: الطعام والقهوة |
| الوحدة ٤ | سنع الطريق والتواصل والزيارات |
| الوحدة ٥ | سنع الأسرة والعلاقات الاجتماعية |
| الوحدة ٦ | سنع المناسبات والملبس |
| الوحدة ٧ | مكارم الأخلاق العامة |
| الوحدة ٨ | السنع الرقمي والمعاصر *(مضافة)* |
| المشروع الختامي | «راوي السنع»: بحث ميداني وتوثيق بثلاثة مسارات حسب المستوى |
| الملاحق | معجم المفردات، وثبت المصادر، وسجلّ التوثيق |

في نهاية كل وحدة قسم **المراجعة والتقييم**: اختيار من متعدد، وصواب وخطأ، وأسئلة مقالية متدرجة (م١، م٢، م٣)، ومواقف سلوكية، وسلالم تقدير، ومفتاح إجابة للمعلم.

## ضوابط النزاهة العلمية

- الأحاديث النبوية مخرّجة من مصادرها الأصلية، والآيات مطابقة على رواية حفص.
- لم يُعتمد أي مصدر شيعي.
- كل مثل شعبي موسوم بحالته: **موثَّق** في مصدر منشور، أو **يُوثَّق يدوياً** إن ورد في المسودة الأصلية واعتُمد في المتن بانتظار توثيقه.
- حُجب شعر الشعراء المعاصرين (حمد بوشهاب، سالم الجمري) حتى الاستئذان من أصحاب الحق.
- العناصر المعتمدة بانتظار التوثيق اليدوي في [`docs/verification-log.md`](docs/verification-log.md).

## بنية المستودع

```
book/index.html          الصفحة الرقمية
dist/                    طبعتا PDF وWord
source/                  المسودة الأصلية (docx) ونصها المستخرج (md)
src/parts/               أجزاء المتن (HTML) — مصدر التحرير الوحيد
src/build/               سكربتات البناء
docs/                    سجلّ التوثيق
```

## إعادة البناء

يُحرَّر المتن في `src/parts/` فقط، ثم:

```bash
bash src/build/build.sh
```

المتطلبات: Python 3 مع `beautifulsoup4` و`playwright` (Chromium)، وNode.js مع حزمة `docx`، وخط **Noto Naskh Arabic** مثبّتاً على الجهاز.
